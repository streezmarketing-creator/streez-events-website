STREEZ EVENTS — GITHUB PAGES EASY UPLOAD

FILES
- index.html: main website, original visual design retained, promotional business messaging, enquiry form connected to Apps Script
- thankyou.html: thank-you page with Google Ads global tag and a WhatsApp follow-up popup after 5 seconds
- streez-logo.svg and WhatsApp logo image: existing brand assets

UPLOAD
1. Extract this ZIP.
2. In your GitHub repository, upload/replace all files in the repository root (do not upload the ZIP itself).
3. Commit changes to the main branch.
4. GitHub repository Settings > Pages > Deploy from a branch > main > /(root) > Save.

FORM
The form sends name, phone, service and city to the deployed Google Apps Script endpoint configured in index.html. It then opens thankyou.html with the lead summary and WhatsApp link. The browser uses no-cors, so it cannot read the server response; verify successful lead capture by checking the Google Sheet.

GOOGLE ADS
Global Google tag AW-18329237137 is installed on both the main page and thank-you page. The thank-you page fires a generate_lead event. A Google Ads conversion action event requires the conversion label from Google Ads; it has not been guessed.
