STREEZ EVENTS — SIMPLE GITHUB PAGES PACKAGE

Website form is connected to your latest Google Apps Script Web App URL. The original page content, styling, brand logo, local logo image, gallery image URLs, WhatsApp flow, and thank-you page are included.

UPLOAD STEPS (no coding/build needed):
1. Extract this ZIP on your computer.
2. Open GitHub.com and create a NEW repository named streez-events-website. Public is easiest for GitHub Pages.
3. In the repository, click Add file → Upload files. Upload all 5 files from this extracted folder. Do NOT upload the ZIP itself.
4. Click Commit changes.
5. Open repository Settings → Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select Branch: main and Folder: /(root), then Save.
8. Wait for the Pages URL to appear. It will look like https://YOUR-GITHUB-USERNAME.github.io/streez-events-website/

IMPORTANT:
- Check that index.html and thankyou.html are at the root of the repository, not inside another folder.
- Submit one test enquiry on the live page, then refresh your Google Sheet and check the Sheet1 tab.
- Because the browser cannot read an Apps Script cross-origin response, the page cannot truthfully confirm the row from the browser alone. The real test is whether the new row appears in Sheet1.
- The hero/gallery photos use the same remote image URLs included by the original HTML; the STREEZ logo image and SVG are included locally in this ZIP.
